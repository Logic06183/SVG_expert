1. Gradient Descent Basic

⏱️ 12 seconds 📐 Optimization

Watch how gradient descent finds the minimum of a loss function. The ball rolls downhill following the negative gradient, converging to the optimal parameters.

Key Insight: Optimization works by following gradients to minimize loss.

2. Decision Tree Building Basic

⏱️ 20 seconds 🌳 Tree Models

See how decision trees recursively split data to create pure regions. Each split minimizes impurity (Gini), and the tree structure emerges in parallel.

Key Insight: Trees learn by finding splits that maximize information gain.

3. Random Forest Ensemble Intermediate

⏱️ 25 seconds 🌲 Ensemble

Four individual trees (each overfitting) combine to create a smooth, robust ensemble. Bootstrap sampling creates diversity, averaging reduces variance.

Key Insight: High variance (single tree) → Low variance (forest average).

4. Gradient Boosting Advanced

⏱️ 25 seconds 🚀 Boosting

Each new tree corrects the residual errors of the previous ensemble. Watch predictions improve and residuals shrink over 5 iterations.

Key Insight: Sequential error correction: each tree fits the mistakes of the ensemble.

5. Backpropagation Advanced

⏱️ 20 seconds 🧠 Neural Networks

Forward pass (blue wave) computes predictions. Backward pass (red wave) propagates gradients via chain rule. All weights update simultaneously.

Key Insight: Gradients flow backward through the network, updating all weights.

6. Bias-Variance Tradeoff Intermediate

⏱️ 18 seconds ⚖️ Fundamentals

Model complexity increases from simple (underfit) to optimal (just right) to complex (overfit). Validation error reveals the sweet spot.

Key Insight: Balance bias and variance—not too simple, not too complex.

7. Learning Rate Effect Intermediate

⏱️ 15 seconds 🎯 Hyperparameters

Three parallel gradient descents show: too small (slow), optimal (smooth), and too large (diverges). Learning rate is critical!

Key Insight: Learning rate must be tuned—too small is slow, too large is unstable.

8. Feature Importance Basic

⏱️ 12 seconds 📊 Interpretation

Watch feature importance bars grow as 100 trees are added to the Random Forest. Temperature emerges as the most important predictor.

Key Insight: Feature importance reveals which variables drive predictions.
