# Usage Examples

Real-world examples of requesting slides from the SVG Slide Master skill.

## Example 1: Research Presentation Series

**Scenario:** Creating a complete presentation for a climate health conference.

### Request 1: Title Slide
```
Create a title slide for my presentation:
Title: "Urban Heat Islands and Cardiovascular Mortality"
Subtitle: "A 10-Year Cohort Study in Johannesburg"
Author: Dr. Sarah Nkosi, Wits Planetary Health Research
Date: November 2025
```

**Result:** Professional title slide with centered layout, gradient accent, and proper hierarchy.

---

### Request 2: Background Context
```
Generate a content slide titled "Background" with these points:
• Urban heat islands intensify heat exposure in cities
• Cardiovascular disease is sensitive to temperature extremes
• Johannesburg has experienced 1.2°C warming since 1990
• Vulnerable populations face disproportionate risk

Add a simple icon representing urban heat on the right side
```

**Result:** Content with visual layout (template 02), bullet points on left, icon/graphic on right.

---

### Request 3: Key Finding
```
Create a key message slide with this finding:
"23% increase"
in cardiovascular mortality during heat waves
Source: "Wits PHR Urban Health Study, 2024"
```

**Result:** High-impact slide (template 04) with large statistic, supporting text, and source citation.

---

### Request 4: Data Visualization
```
Generate a bar chart slide showing cardiovascular mortality by temperature category:
```

## Example 3: Academic Seminar

**Scenario:** Weekly research seminar presentation.

### Request 1: Methodology Overview
```
Create a content slide for methodology:
Title: "Data Collection Methods"

Methods:
• Temperature monitoring: 24/7 urban weather stations (n=12)
• Health records: Hospital admissions data (2015-2025)
• Exposure assessment: Geographic information systems (GIS)
• Statistical analysis: Distributed lag non-linear models

Add a simple flowchart on the right showing: Data → Analysis → Results
```

**Result:** Methodological content slide with bullet points and process flow.

---

### Request 2: Statistical Results
```
Make a slide showing model results:
Title: "Temperature-Mortality Relationship"

Create a line chart with temperature (x-axis, 0-40°C) and relative risk (y-axis, 0.5-2.5).
Show a U-shaped curve: RR=1.2 at 5°C, RR=1.0 at 25°C (baseline), RR=1.8 at 40°C.
Use navy for the line, add confidence interval shading in light blue
Caption: "Relative risk of cardiovascular mortality by daily maximum temperature"
```

**Result:** Custom data visualization with line chart and confidence intervals.

## Tips for Each Scenario

### Research Presentations
- Start with a strong title slide
- Use section headers to structure the talk
- Balance text and visuals (50/50)
- Highlight key findings with impactful slides

### Policy Briefs
- Lead with key messages
- Use simple, clear visuals
- Emphasize actionable insights
- Include source citations

### Academic Seminars
- Show methodological detail
- Include statistical results
- Provide comprehensive captions
- Use technical language appropriately

### Internal Meetings
- Keep it concise
- Use status indicators
- Focus on action items
- Quick visual scan

### Data Dashboards
- Emphasize key metrics
- Use color coding
- Show trends and comparisons
- Regular, consistent format

### Conference Posters
- Adapt dense content
- Multi-column layouts
- Integrate figures centrally
- Include all necessary details

## Common Patterns

### Pattern 1: Introduction Sequence
1. Title slide
2. Background/Context
3. Research Question (key message slide)
4. Objectives (content slide)

### Pattern 2: Results Sequence
1. Section header "Results"
2. Overview (content slide with 3-4 key findings)
3. Finding 1 (data visualization)
4. Finding 2 (data visualization)
5. Finding 3 (data visualization)
6. Summary (key message slide)

### Pattern 3: Discussion Sequence
1. Section header "Discussion"
2. Key Implications (content slide)
3. Comparison to Literature (content with visual)
4. Limitations (content slide)
5. Future Directions (content slide)

### Pattern 4: Conclusion Sequence
1. Take-Home Message (key message slide)
2. Recommendations (content slide)
3. Acknowledgments (simple text slide)
4. Thank You + Contact (title-style layout)

## Pro Tips

1. **Be specific with data** - Actual numbers produce better charts than "show some data"
2. **Reference templates** - "Use template 04" saves time and ensures desired layout
3. **Specify colors by name** - "Use navy" is clearer than "use the primary color"
4. **Include context** - Mentioning the presentation type helps tailor the output
5. **Request source citations** - Always include "add source citation" for data slides
